# tidal_lock

### Сборка и запуск проекта

1. Создать директорию для сбоки в корне проекта и перейти в нее

```bash
cmake -B build
cd build
```

2. Создать Makefile, собрать исполняемый файл и запустить программу
```bash
cmake && make && ./app
```

Возможны ошибки, если в системе не найдены все необходимые пакеты. Их нужно установить
